# 🎨 Стайлгайд (Styleguide)

Правила оформления текстов и документации.

## 1. Язык

- **Интерфейс:** только русский.
- **Документация:** русский.
- **Код:** английский (camelCase, PascalCase).

## 2. Форматирование текста

- **Заголовки:** начинай слово до двоеточия с прописной буквы.
- **После двоеточия:** пиши со строчной, если текст продолжает строку.
- **После эмодзи:** 🎨 Текст сразу после эмодзи — с прописной.
- **Техническая лексика:** Sentence Case, но сохраняй регистр брендов (Vue, TypeScript) и Title Case для терминов.
- **Новые предложения:** внутри пункта списка — с прописной.

## 3. Типографика

- **Дефис:** используй только `-`. Никаких `—` или `–`.

## 4. Стиль

- **Живой язык:** никаких канцеляризмов, штампов, вводных конструкций.
- **Краткость:** минимум слов, максимум смысла.
- **Глаголы в кнопках:** инфинитив ("Добавить", не "Добавление").

## 5. Сообщения об ошибках

- Понятные пользователю, без технических терминов.
- ✅ "Не удалось сохранить. Попробуйте ещё раз."
- ❌ "Error: localStorage quota exceeded"
